# Автотесты для API «Прилавок»

Проект содержит автоматизированные тесты для API «Прилавок» - проверка поля `name` в запросе на создание набора продуктов (раздел **Main.Kits → Создание набора**).

Тесты реализуют чек-лист из 11 проверок: граничные значения длины, допустимые и недопустимые типы данных, спецсимволы, пробелы, буквы и цифры.

## Стек

- Python 3
- pytest
- requests

## Структура проекта

| Файл | Назначение |
|------|------------|
| `configuration.py` | URL сервера и эндпоинты API |
| `data.py` | Тестовые данные: заголовки, тела запросов, значения для проверок |
| `sender_stand_request.py` | Функции для отправки HTTP-запросов к API |
| `create_kit_name_kit_test.py` | Тесты по чек-листу для поля `name` |
| `README.md` | Описание проекта |
| `.gitignore` | Исключения для Git |

## Что проверяется

Чек-лист для поля `name` при создании набора:

1. Допустимое количество символов (1) → ✅ 201, `name` совпадает
2. Допустимое количество символов (511) → ✅ 201, `name` совпадает
3. Количество символов меньше допустимого (0) → ❌ 400
4. Количество символов больше допустимого (512) → ❌ 400
5. Английские буквы → ✅ 201, `name` совпадает
6. Русские буквы → ✅ 201, `name` совпадает
7. Спецсимволы → ✅ 201, `name` совпадает
8. Пробелы → ✅ 201, `name` совпадает
9. Цифры → ✅ 201, `name` совпадает
10. Параметр не передан → ❌ 400
11. Передан другой тип параметра (число) → ❌ 400

> Некоторые проверки ожидаемо возвращают FAILED — это соответствует чек-листу и не является ошибкой автотестов.

## Подготовка к запуску

Перед запуском тестов необходимо:

1. Запустить сервер «Прилавка».
2. Убедиться, что в `configuration.py` указан корректный URL сервера.
3. Установить зависимости:

```bash
pip install pytest requests
```

## Запуск тестов

Из корневой папки проекта:

```bash
pytest create_kit_name_kit_test.py
```
